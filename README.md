# SuperBuffer

Adaptive Input Buffering for Geometry Dash

SuperBuffer is an experimental Android64 Geode mod for Geometry Dash, focused on improving input responsiveness through configurable frame windows and predictive input buffering.

Compatibility

- Geometry Dash: 2.2081
- Geode: 5.11.2
- Platform: Android64

Features

Current Features

- Input event tracking
- Frame timing tracking
- Game mode detection
- Configurable buffer windows
- Separate Normal and Practice profiles
- P1 and P2 input tracking
- Independent input queues for P1 and P2
- Dual mode compatibility groundwork
- Geode settings integration

Supported Game Modes

- Cube
- Ship
- Ball
- UFO
- Wave
- Robot
- Spider
- Swing

Configuration

SuperBuffer provides configurable frame-window settings through the Geode mod settings menu.

Each supported game mode has its own buffer-window setting.

Development Status

<text>SuperBuffer is currently in experimental development.</text>

The input tracking, frame timing, mode detection, and queue infrastructure are being developed and tested.

Important: Actual predictive input buffering and automatic input replay are not yet implemented.

Installation

1. Download the Android64 ".geode" build from the project's GitHub Actions artifacts.
2. Install the file using Geode.
3. Open Geometry Dash.
4. Find SuperBuffer in Geode's mod settings.

Project Goals

- Implement reliable predictive input buffering.
- Improve input responsiveness.
- Support all eight game modes.
- Maintain P1 and P2 independence in Dual mode.
- Provide customizable frame windows.
- Keep performance suitable for Android devices.
